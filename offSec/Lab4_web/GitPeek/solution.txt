GitPeek: the website let you search log files via branch or tags name. I know that there is a FLAG variable in the environment. Some character are forbidden, for example ; && or other. But the $ sign is allowed. the shell resolve a variable before executing the command, that in this case is git log [input], so sending something like git log $VAR will result in git log [actual value of VAR]. sending $FLAG will result in an error, because there are no any logs with that variable name. But, before returning the error, the shell will resolve the value. So, we don’t see the usual error “ambiguous argument $FLAG” but “ambiguous argument 'offsec{g1t_p33k_cmd_sub_t2AUqffjlkQYgtrh}’”
